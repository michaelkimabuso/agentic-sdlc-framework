# Agentic SDLC Framework

A reusable, tool-agnostic framework for guiding AI coding agents through software delivery with explicit artifacts, verification, and human approval gates.

## Initial scope

The first milestone is Idea to PR (M1), with guided execution and explicit human approval gates. Later milestones may extend the workflow through deployment, feedback, and controlled automation.

The framework separates the workflow definition, artifact templates, and coding-agent adapter so the process can evolve without tying the core to one tool.
